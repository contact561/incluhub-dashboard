# IncluHub Dashboard Agent Instructions

Before coding, always read:

- docs/PROJECT_RULES.md
- README.md

Follow the MVP scope strictly.

Do not build:
- Payments
- WhatsApp automation
- AI features
- CRM
- Marketplace
- Mobile app
- Certificate automation
- Advanced analytics
- Public signup

Important rules:
- No public signup
- No role selection on login
- Admin creates all users
- Role comes from profiles table
- Every protected action must be checked server-side
- Never expose SUPABASE_SERVICE_ROLE_KEY to the browser
- Do not build the full app at once
- Only complete the current requested module
